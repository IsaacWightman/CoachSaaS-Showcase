# CoachSaaS - Sports Academy Management Platform

CoachSaaS is a comprehensive Software-as-a-Service (SaaS) solution designed to modernize how sports academies, coaches, and teams manage their operations. From scheduling and roster management to payments and player development tracking, CoachSaaS streamlines the administrative burden so coaches can focus on what matters most: coaching.

## 🛠️ Technology Stack

- **Frontend**: React (v18+), Vite
- **Styling**: Tailwind CSS, Radix UI, Lucide React
- **Backend**: Supabase (PostgreSQL, Auth, Realtime)
- **Testing**: Playwright
- **State Management**: React Query / TanStack Query
- **Forms**: React Hook Form, Zod
